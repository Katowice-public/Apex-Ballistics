# Sound credits

The sound files in this directory are from the **50 CC0 Sci-Fi SFX**
collection hosted by CC0 Sounds:

https://cc0-sounds.exi.software/collection/50-cc0-sci-fi-sfx/

The source collection is released under **CC0 1.0 Universal**. Files were
renamed for their in-game roles but are otherwise distributed as source OGG
assets.
